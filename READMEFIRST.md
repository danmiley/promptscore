# READMEFIRST

This repo carries an installed polymath skill stack (see `docs/polymath-install.toml` for what and which version).

## Start Here
1. Read `AGENTS.md`.
2. Read `docs/starting-prompt.md`.
3. Read `docs/ARCHITECTURE.md`.
4. Read `docs/ai-memory/INDEX.md` when present.
5. Read each installed skill `SKILL.md` that applies to your task; open referenced detail files only when needed.

## Expected Workflow
1. Confirm branch and working-tree state.
2. Read the files that define the area you will change.
3. Check that `.gitignore` matches the artifacts your work is likely to generate.
4. Make a focused patch.
5. Run validation commands from `AGENTS.md` or explain why they could not run.
6. Update `docs/ENGINEERING_LOG.md` when work changes repo behavior, infrastructure, release process, or policy.
