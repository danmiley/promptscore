# Sample prompts

Dummy inputs for `scripts/score_prompt.py`. They are not user data.

| File | What it is for |
| --- | --- |
| `thin-request.md` | Vague wording, no finish line. |
| `partial-task.md` | A real file and a boundary, no check. |
| `disciplined-task.md` | Finish line, boundary, output, and a reported check. |
| `multi-part-unchecked.md` | Several numbered asks and no per-step check. |
